# 基金策略管家

## 🚀 基金策略管家 v3.0 - 全面进阶版发布

在原版“纪律化监控”的基础上，本次更新迎来了更进一步的升级。除了继续强化分组管理、批量导入和监控展示之外，最核心的变化是把交易流程做成了“当日可提交、次日自动结算、列表实时提示”的完整闭环，让日常记录更贴近真实操作节奏。

---

## 🧠 核心策略（变化最大的部分）

- **当日交易可直接提交**：买入和卖出都可以先录入，当天先进入待处理状态，不再强制等到次日。
- **名称下小字提示**：提交后会在基金名称下显示“小字状态”，例如待买入xx元、待卖出xx份。
- **T+1 自动结算**：到达可结算时间后，系统会自动切换为一笔买入中、一笔赎回中，并在 T+1 15:00 之后自动消失。
- **按交易日自动查价**：结算时会优先使用交易日历史净值，尽量保证金额、份额和单价一致。
- **持仓状态自动判断**：有交易记录且市值大于 0 时显示为实际持有；无交易记录或全部卖出后则显示为仅观察。
- **持仓份额自动保留两位**：配置中的持仓份额会自动四舍五入，避免过长小数影响查看。

---

## ✨ 本次全新亮点功能

- 📑 **基金分组全面管理**：支持新建、重命名、删除分组，基金可以在多个分组之间移动或复制。
- 🧩 **当前分组资产总览**：基金监控列表顶部会显示当前分组的基金数、预警数、市值和盈亏汇总。
- 🖱️ **列顺序与列宽自定义**：表头支持拖拽调整顺序，列宽可以手动拖动调整，并会记住你的设置。
- 🤖 **自动查询基金名称**：添加基金时只需要输入代码，系统会自动查询并填入基金名称。
- 🧮 **批量导入基金与交易**：支持一次性导入多只基金，也支持批量导入交易记录。
- 🎯 **单基金操作面板**：点击基金名称可以打开操作入口，执行交易、编辑、删除、移动分组等操作。
- 🎨 **列表视觉优化**：信号状态、行高亮、按钮样式和名称下的小字提示都做了统一优化，保持更清晰的浏览体验。

## 📦 使用方法

1. 双击 Start.bat。
2. 或双击 双击启动.bat。
3. 程序会自动启动服务并打开浏览器。
4. 开始添加基金、录入交易并查看分组监控。

默认地址：http://127.0.0.1:5000

---

## ⚠ 注意

如果 Windows 拦截并提示风险：

1. 点击“更多信息”。
2. 再点击“仍要运行”。

这是一个纯本地运行的工具，不会主动上传你的基金数据。

## 📁 目录说明

- app.py：后端服务、数据库、交易与结算逻辑
- static/app.js：前端交互、列表渲染、批量导入、弹窗操作
- static/style.css：页面样式
- templates/index.html：页面结构
- Start.bat：源码运行入口
- BuildShareable.bat：打包入口
- Run_Portable.bat：便携版启动模板

---

## ⚙ 配置项

可选环境变量：

- FUND_HOST：默认 127.0.0.1
- FUND_PORT：默认 5000
- FUND_DEBUG：默认 0
- FUND_OPEN_BROWSER：源码运行时默认 0，打包运行时默认 1

## 💾 数据文件

数据库文件为 fund_strategy.db。

- 打包运行时：位于 exe 所在目录

## ❓ 常见问题

### 为什么我改了样式，页面没变化？

通常是浏览器缓存或后台进程没有重启到最新代码。建议确认当前只运行一份服务，并刷新页面。

### 为什么看不到当天交易提示？

请检查交易是否已经提交到当前正在运行的服务，并确认页面已经刷新到最新数据。

### 数据会丢失吗？

不会。只要 fund_strategy.db 保留，数据就会继续存在。
