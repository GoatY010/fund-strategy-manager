# 基金策略管家

## 🚀 基金策略管家 v3.9.0 - 收益口径统一与刷新优化版

在前几个版本持续强化分组管理、批量导入和列表交互之后，这一版的重点转向了“把数据算准、把刷新做快、把操作做顺”。这次不再只是增加入口，而是把行情读取、收益展示、交易结算和表格交互整体梳理了一遍，让日常使用更稳定，也更接近真实交易节奏。

---

## 🧠 核心策略（变化最大的部分）

- **行情刷新优先走本地缓存**：已经存在的当日行情和历史净值优先复用，本地没有再并行补拉，刷新更快也更稳。
- **收益口径统一**：昨日涨跌、当日盈利、市值和持有收益统一计算与展示，零值不再被隐藏成空白。
- **未结算交易独立处理**：待结算交易与已结算交易分开统计，避免 pending 记录影响持有收益和累计盈亏。
- **交易按日期自动取价**：今日交易优先使用当前估值，历史交易优先按交易日净值取价，减少手工修正。
- **列表展示更直观**：新增当日盈利和昨日涨跌，持有收益同时显示金额和收益率，查看仓位表现更直接。
- **交互更贴近日常使用**：交易弹窗会自动带出当前估值，刷新时也会同步更新弹窗里的价格。

---

## ✨ 本次全新亮点功能

- 📑 **基金分组全面管理**：支持新建、重命名、删除分组，基金可以在多个分组之间移动或复制。
- 🧩 **当前分组资产总览**：基金监控列表顶部会显示当前分组的基金数、预警数、市值、当日盈利和总盈亏汇总。
- 🖱️ **列顺序与列宽自定义**：表头支持拖拽调整顺序，列宽可以手动拖动调整，并会记住你的设置。
- 🤖 **自动查询基金名称**：添加基金时只需要输入代码，系统会自动查询并填入基金名称。
- 🧮 **批量导入基金与交易**：支持一次性导入多只基金，也支持批量导入交易记录。
- 🎯 **单基金操作面板**：点击基金名称可以打开操作入口，执行交易、编辑、删除、移动分组等操作。
- 🎨 **列表视觉优化**：信号状态、行高亮、按钮样式和名称下的小字提示都做了统一优化，保持更清晰的浏览体验。
- 🚀 **行拖拽排序记忆**：基金行支持拖拽调整顺序，并会自动保存你的排列习惯。

## 📦 使用方法

1. 双击 Start.bat。
2. 或双击 双击启动.bat。
3. 程序会自动启动服务并打开浏览器。
4. 开始添加基金、录入交易并查看分组监控。

默认地址：http://127.0.0.1:5000

---

## ⚠ 注意

如果 Windows 拦截并提示风险：

1. 点击“更多信息”。
2. 再点击“仍要运行”。

这是一个纯本地运行的工具，不会主动上传你的基金数据。

## 📁 目录说明

- app.py：后端服务、数据库、交易与结算逻辑
- static/app.js：前端交互、列表渲染、批量导入、弹窗操作
- static/style.css：页面样式
- templates/index.html：页面结构
- Start.bat：源码运行入口
- BuildShareable.bat：打包入口
- Run_Portable.bat：便携版启动模板

---

## ⚙ 配置项

可选环境变量：

- FUND_HOST：默认 127.0.0.1
- FUND_PORT：默认 5000
- FUND_DEBUG：默认 0
- FUND_OPEN_BROWSER：源码运行时默认 0，打包运行时默认 1

---

## 💾 数据文件

数据库文件为 fund_strategy.db。

- 源码运行时：位于项目运行目录
- 打包运行时：位于 exe 所在目录

只要 fund_strategy.db 保留，数据就会继续存在。

## ❓ 常见问题

### 为什么我改了样式，页面没变化？

通常是浏览器缓存或后台进程没有重启到最新代码。建议确认当前只运行一份服务，并刷新页面。

### 为什么看不到当天交易提示？

请检查交易是否已经提交到当前正在运行的服务，并确认页面已经刷新到最新数据。

### 数据会丢失吗？

不会。只要 fund_strategy.db 保留，数据就会继续存在。
