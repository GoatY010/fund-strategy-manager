# 基金策略管家 (Fund Strategy Manager) v2.0

这是一个本地运行的基金策略辅助工具，旨在帮助你严格执行低买高卖的纪律化基金持仓管理。

##  v2.0 全新特性
- **自定义预警配置**：支持为不同基金量身定制 1%、2%、3%、5%、10% 的专属买卖提醒。
- **自定义分组标签**：支持打标签分组（如宽基、行业），顶部自动生成一键切换 Tab。
- **智能查价联动**：填写日期后，自动调用全网接口抓取并填入对应的历史真实净值。
- **双向折算辅助**：录入交易时金额与份额智能反算，懒人首选。
- **高自由度排版**：支持浏览器端拖拽调整监控表格列顺序，本地免登录记忆。
- **撤销与重算**：支持撤销单笔交易，并完美回退资金与上次成交基准线。

##  开发者快速上手
如果你在本机拥有 Python 环境：
- 方式一：直接双击 Start.bat（会自动寻找/创建虚拟环境并启动后台和浏览器）。
- 方式二：在终端中 conda activate 你的环境，然后运行 python app.py。
默认访问地址：http://127.0.0.1:5000

##  一键打包发给小白
